# 패션 플랫폼 사용자 행동 분석

직접 설계·수집한 설문으로 패션 플랫폼 이용자의 추천 의향, 지속 이용 의향, 자기보고 구매 활동과 불편 경험을 분석한 개인 프로젝트다. 여러 플랫폼 사용자의 응답을 함께 살펴봤으며, 특정 기업의 고객 데이터나 서비스 성과를 분석한 것은 아니다.

> 불편을 느끼면서도 계속 이용하는 사용자에게 추천 의향은 이용·구매 활동과 얼마나 같은 신호일까?

## 1. 문제 정의와 가설

추천 의향과 지속 이용 의향이 일치하는지, 추천 의향이 구매 활동과도 연결되는지 확인했다. 최초 인지 채널과 최근 구매 영향 채널의 응답을 비교하고, 선택형·자유응답에서 반복되는 불편을 후속 탐색했다.

- **가설 1.** 추천 의향이 높을수록 지속 이용 의향도 높을 것이다.
- **가설 2.** 추천 의향이 높을수록 자기보고 구매 빈도는 높고 최근 구매 시점은 가까울 것이다.
- **가설 3.** 최초 인지 채널에 따라 같은 채널이 최근 구매에도 영향을 줬다고 응답한 비율은 다를 것이다.

## 2. 분석 기준

Google Forms 원본 269건에서 논리 모순 3건을 제외해 266건을 분석했다. 질문마다 응답 대상이 달라 분모를 구분했다.

| 분석 대상 | 규모 | 사용한 분석 |
|---|---:|---|
| 정제 응답 | 266명 | 표본 특성 |
| 플랫폼 사용자 | 200명 | 가설 1, 선택형 불편 Q13 |
| 최근 6개월 구매자 | 191명 | 가설 2 |
| 공통 3채널 최초 인지자 | 155명 | 가설 3 |
| 유효 자유응답 | 92건 | Q18 다중 라벨 탐색. 이 중 플랫폼 사용자는 68건 |

정제 응답에서 20대는 **194/266명(72.9%)**, 여성은 **140/266명(52.6%)**, 남성은 <strong>126/266명(47.4%)</strong>이었다. 이 자료는 편의표본의 단면 설문이며, 구매 빈도와 최근성은 실제 거래 기록이 아닌 자기보고 응답이다.

SQL로 분석 집단과 지표를 고정하고, Python에서 순위상관·채널 비교·자유응답 유형을 확인했다. 변수와 문항별 분모는 [변수 정의](docs/variables.md), 분석 방법은 [방법론](docs/METHODS.md)에 정리했다.

## 3. 검증 결과

### 가설 1 · 추천 의향과 지속 이용 의향

플랫폼 사용자 **200명**에서 두 의향은 양의 관계(ρ≈.400)였다. NPS는 **−32.0**, 긍정 지속 이용 의향은 <strong>187/200명(93.5%)</strong>이었다. 비추천자에서도 <strong>77/88명(87.5%)</strong>이 긍정 지속 이용 의향을 답해 두 태도가 완전히 일치하지는 않았다.

### 가설 2 · 추천 의향과 구매 활동

최근 6개월 구매자 **191명**에서 추천 의향은 자기보고 구매 빈도(ρ=.248)와 최근성(ρ=.186)에 모두 **약한 양의 관계**를 보였다. 추천 의향 집단별 구매 응답 분포도 넓게 겹쳤다.

### 가설 3 · 인지 채널과 구매 영향 채널

공통 주요 채널로 처음 인지한 **155명** 중 같은 채널을 최근 구매 영향 채널로도 답한 비율은 **유튜브 14/23명(60.9%)**, **SNS 48/84명(57.1%)**, <strong>친구·지인 10/48명(20.8%)</strong>이었다. 채널 간 차이는 χ²=18.447, Cramér’s V=.345였다. 두 문항의 회상 응답을 비교한 결과다.

### 후속 탐색 · 선택형과 자유응답 불편

- **Q13 선택형 · 플랫폼 사용자 200명 · 복수응답:** 사이즈 문제 **102명(51.0%)**, 실제 상품이 사진과 달랐음 **88명(44.0%)**, 배송이 느렸음 **48명(24.0%)** 순이었다.
- **Q18 자유응답 · 유효 92건 · 다중 라벨:** 사이즈·핏 **39건(42.4%)**, 추천·검색 **24건(26.1%)**, 정보·리뷰 **21건(22.8%)** 순이었다. 이 비율은 자유응답 92건 안에서의 언급 비중이다.

성별 세부 비교에서 Q13의 **사진과 실제 상품의 차이**는 여성 63/121명(52.1%), 남성 25/79명(31.6%)으로 **20.5%p 차이**가 있었다. Q18의 **정보·리뷰** 언급도 여성 16/45명(35.6%), 남성 5/47명(10.6%)으로 **25.0%p 차이**가 관찰됐다. 사이즈·핏 언급률은 남녀 모두 42%대로 비슷했다.

## 4. 분석을 통해 확인한 패턴

- **추천 의향과 이용·구매 활동은 같은 지표로 보기 어려웠다.** 추천 의향은 지속 이용 의향과 양의 관계를 보였지만, 비추천자에서도 높은 지속 이용 의향이 나타났다. 구매 빈도·최근성과의 관계도 양의 방향이었으나 그 크기는 상대적으로 약했다.
- **인지와 최근 구매 영향에서 채널의 연결 정도는 채널별로 달랐다.** SNS와 유튜브는 처음 인지한 채널을 최근 구매 영향 채널로도 답한 비율이 절반 이상이었던 반면, 친구·지인은 상대적으로 낮았다.
- **사이즈·핏 관련 불편은 질문 방식이 다른 Q13과 Q18에서 모두 반복됐다.** 성별 세부 결과에서는 일부 상품 정보·리뷰 관련 항목에서도 응답 비율 차이가 관찰됐다.

이러한 결과는 특정 플랫폼의 성과나 원인을 의미하기보다, 이번 설문 응답에서 반복적으로 확인된 사용자 태도와 경험의 패턴으로 해석했다.

원본 설문 CSV에는 추첨용 이메일이 있어 저장소에서 제외했다. Q18 확정 라벨 CSV와 MySQL 접속 정보도 공개하지 않아, 공개 저장소만으로 전체 분석을 재실행할 수는 없다.

다음 분석에서는 추천 의향과 지속 이용 의향이 가리키는 플랫폼을 명확히 맞추고, ‘불편을 느끼면서도 계속 이용하는 이유’를 직접 묻는 문항을 추가할 계획이다.
