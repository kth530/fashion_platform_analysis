# 패션 플랫폼 사용자 행동 분석

> **포트폴리오 최종 읽기 순서:** [01 문제·가설](notebooks/01_problem_hypothesis.md) → [02 데이터 준비](notebooks/02_data_preparation.ipynb) → [03 데이터 개요](notebooks/03_data_overview.ipynb) → [04 EDA·검증·판단](notebooks/04_eda_validation.ipynb).

**질문:** 추천 의향과 지속 이용·구매 신호가 엇갈릴 때, 사용자 상태와 개선 후보를 어떤 근거로 판단해야 할까?

직접 설계·수집한 설문을 정제하고, 문항별 분모를 나눠 NPS와 지속 이용 의향, 자기보고 구매 활동의 관계를 확인했다. 이어 선택형 불편과 자유응답으로 UX 검증 후보를 좁혔다. 이 프로젝트의 결론은 **NPS만으로 이탈이나 실제 구매를 판단할 수 없으며, 사이즈·핏 정보는 로그와 실험으로 확인할 후보**라는 것이다.

> [변수·분모 정의](docs/variables.md) · [방법론](docs/METHODS.md)

## 1. 직접 설문, 정제, 분모 확인

Google Forms로 **269건**을 수집했다(2026-04-25 ~ 2026-05-16). 사용 여부와 구매 여부에 따른 문항 분기를 확인하고, 플랫폼명·인지 경로를 정규화했다. 응답 간 **논리 모순 3건**을 제외해 266건을 남겼으며, 추첨용 이메일은 분석 테이블에서 분리했다. 질문마다 대상이 달라 분모를 다음처럼 사용했다.

| 분석 대상 | 응답자 수 | 쓰임 |
|---|---:|---|
| 정제된 전체 응답자 | **266명** | 표본 특성과 설문 흐름 |
| 플랫폼 사용자 | **200명** | NPS, 지속 이용 의향, 선택형 불편(Q13) |
| 최근 6개월 구매자 | **191명** | 구매 빈도·최근성(Q9·Q10)과 NPS의 관계 |
| 유효 자유응답자 | **92명** | 개선 의견(Q18)의 후속 탐색. 이 중 플랫폼 사용자는 68명 |

전체 응답자의 72.9%가 20대인 **편의표본**이다. 구매 관련 문항은 거래 로그가 아닌 **자기보고 구매 활동**이므로 시장 전체 비율이나 관측 구매 행동으로 해석하지 않는다. Q18은 비결측 93건 중 무의미한 답변 1건을 제외한 92건을 분석했다.

## 2. NPS와 지속 이용 의향 비교

플랫폼 사용자 200명의 **NPS Score는 −32.0**이었다. 한편 **187/200명(93.5%)**이 긍정적 지속 이용 의향을 답했고, Detractor에서도 **77/88명(87.5%)**이 긍정적으로 답했다. NPS 집단과 지속 의향 사이에는 관계가 있었지만(병합 교차표 χ²=9.593, p=0.008, Cramér's V=0.219), 낮은 추천 의향을 곧 이탈로 읽을 수는 없다. 병합 후에도 기대빈도 5 미만 셀 1개가 남아 검정은 방향성 근거로 사용했다. [최종 분석 노트북](notebooks/04_eda_validation.ipynb)

## 3. NPS와 자기보고 구매 활동 확인

최근 6개월 구매자 191명에서 NPS 원점수와 **자기보고 구매 빈도**의 스피어만 상관은 ρ=0.248, **자기보고 최근 구매 시점**과는 ρ=0.186이었다. 두 관계 모두 양의 방향이지만 약하다. 설문 문항의 지시 대상과 시간축도 완전히 같지 않다. 따라서 NPS가 실제 구매나 미래 이탈을 예측했다고 해석하지 않는다. [최종 분석 노트북](notebooks/04_eda_validation.ipynb)

## 4. 단독 NPS 판단의 한계에서 UX 후보로

NPS는 추천 의향을 보여주지만, 이 표본에서는 지속 이용 의향 및 자기보고 구매 활동과 완전히 같은 신호가 아니었다. 개선할 문제를 찾기 위해 **선택형 Q13은 불편 항목의 분포**, **자유응답 Q18은 그 불편의 구체적인 모습을 탐색**하는 데 각각 사용했다.

- Q13에서 사이즈 불편은 **102/200명(51.0%)**이 선택했다. 특정 저NPS 집단에만 집중된 항목은 확인되지 않았다. [최종 분석 노트북](notebooks/04_eda_validation.ipynb)
- Q18 유효 자유응답 92건을 전수 감사해 다중 라벨로 분류했다. 사이즈·핏은 **39/92건(42.4%)**, 플랫폼 사용자 응답만 보면 **28/68건(41.2%)**에서 언급됐다. 자동 분류와 최종 라벨이 달랐던 9건을 수정했다. 이는 **자발적으로 답한 사람 안에서의 언급률**이며, 전체 사용자의 불만율이 아니다. [최종 분석 노트북](notebooks/04_eda_validation.ipynb)

두 문항을 함께 보면 **사이즈·핏 정보 개선을 우선 검증할 UX 후보**로 둘 수 있다. 이 자료만으로 사이즈·핏이 낮은 NPS 또는 구매 공백의 원인이라고 단정할 수는 없다. 상세페이지의 실측·착용 후기 같은 개선안을 구체화한 뒤, 상품 상세 조회→장바구니→구매 흐름과 사이즈 사유 반품률·재구매를 **실제 로그와 실험**으로 확인해야 한다.

## 해석 범위

이 설문은 20대 중심 편의표본의 단면·자기보고 자료다. NPS와 지속 의향·구매 활동의 관계는 관찰된 연관성으로 읽는다. Q13은 복수 선택이라 항목별 비율의 분모를 응답자로 두었고, Q18은 자발적 응답자만 포함한다. 실제 잔류·거래·반품 효과를 결정하려면 사용자 로그와 후속 실험이 필요하다.

원본 CSV에는 추첨용 이메일이 있어 공개 저장소에서 제외했다(`raw_data/`는 `.gitignore` 처리). 분석 테이블에는 이메일을 넣지 않았다.
